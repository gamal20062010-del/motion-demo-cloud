# Asset Provenance

This file records the known origin of the creative assets currently used by the Arabic abaya demonstration. It is an origin record, not a blanket license for every asset in the repository.

## Abaya image set

- `Arabic-Kinetic-Video-v2/public/images/abaya-master.webp` is an AI-generated image created by the assistant at the repository owner's request in the prior project workflow. The repository owner confirmed this origin.
- `element-01.png` through `element-04.png` are derived programmatically from the master image by `Arabic-Kinetic-Video-v2/scripts/create_abaya_variants.py`.
- The variants represent visual treatments of the same abaya asset. They are not independent stock photographs.
- Keep the master image and the generation/derivation script together so the variants can be reproduced and their provenance remains traceable.

## Fonts

The project includes Noto Sans Arabic and Noto Naskh Arabic font files obtained from Google Fonts. Their corresponding `OFL.txt` files are stored alongside the font files under `Arabic-Kinetic-Video-v2/public/fonts/`. Consult those license files and the upstream Google Fonts project for the precise font terms.

## Narration and word timing

The current abaya example generates narration using Microsoft Edge TTS with the voice `ar-SA-HamedNeural`. The generated voice and its word-boundary timing data are outputs of the configured TTS pipeline; they are not an original human recording and are not a recording of Sheikh Abdulrazzaq al-Badr or another named speaker.

The narration text and timing output should be reviewed whenever the script or voice changes. Do not describe the timing as forced alignment against an original recording.

## Sound effects

The Pop and Whoosh effects are generated by the project's own script:

- `Arabic-Kinetic-Video-v2/scripts/generate_sfx.py`

The script is the reproducible source for those generated WAV files.

## Contributions and future assets

Before adding an externally sourced photo, video, voice recording, music track, sound effect, icon pack, or font:

1. Record the creator / upstream source and a stable source URL.
2. Record the applicable license or written permission.
3. Confirm that the license permits the intended public distribution and modification.
4. Keep required attribution and license notices with the asset.
5. Do not commit private, personal, or rights-restricted recordings to this public repository.

A file being present in a public repository does not, by itself, establish that it is licensed for reuse.
